## 梳理 IPFS.Avalonia 启动/构造顺序（只读分析，未改代码）

结论：无 DI 容器，`MainWindow` 构造函数即组合根。

构造期（同步，UI 线程）：
1. Program.Main（注册全局/任务异常钩子）→ BuildAvaloniaApp().StartWithClassicDesktopLifetime
2. AppBuilder.Configure\<App\> 内部 new App()
3. App.Initialize() 加载 App.axaml（画刷 + FluentTheme）
4. App.OnFrameworkInitializationCompleted() 挂 UI 线程异常钩子 → new MainWindow()
5. MainWindow ctor 内顺序：InitializeComponent（建可视树，此时无 DataContext、ContentControl.Content 为 null，页面视图都不创建）→ AppConfig.Load（先触发 AppConfig 静态构造：jsonOptions、ApiBaseUrl 读环境变量 IpfsHttpApi）→ new VlcPlaybackService（其字段初始化器 `readonly Video video = new()` 先于 ctor 体，内部 Core.Initialize 加载 libvlc，是启动最重的一步）→ new WindowDialogService(this) → new StatusLogViewModel（建 ThrottledProgress，订阅 AppLog.Message）→ new IPFSService（内部 new SQLiteKit，只 CreateDirectory；SQLiteAsyncConnection 是 `??=` 懒加载，不在此连接）→ new ImagePreviewService（纯静态，空构造）→ new NavigationService → new HomeViewModel → new ShellViewModel（订阅 Navigation.PropertyChanged）→ DataContext = shell → 挂 Opened/Closed
6. Window.Opened（async void lambda）→ shell.InitializeAsync()

显示后：
- Shell.InitializeAsync → Navigation.NavigateRoot(home) → CurrentPage 变化 → ContentControl 走 MainWindow.axaml 的 DataTemplate 实例化 HomeView → home.InitializeAsync
- Home.InitializeAsync → ipfs.InitializeAsync(InitializeTableAsync\<Album\> 建表 → UpdateAlbumAsync 填 AlbumDict) → RefreshAlbums（此处才 new AlbumItemViewModel × N，并限流 3 加载封面）
- 按需创建：ShowSettings → SettingsViewModel/SettingsView；OpenAlbum → DetailViewModel/DetailView（共享同一个 playback 实例）

顺序上的约束（改动时注意）：
- AppConfig.Load 必须早于 IPFSService（否则 SQLiteKit 用默认 Data/IPFSData.db）
- ShellViewModel 构造时 CurrentPage 为 null，IsHomePage=false，顶栏首页按钮初始隐藏
- 单例（playback/log/ipfs/navigation）生命周期=窗口；页面 VM 导航时 new、离栈 Dispose

## 绑定方式梳理（只读分析）

- 项目用 Avalonia 12.1.4，csproj 未设 AvaloniaUseCompiledBindingsByDefault —— **v12 起编译绑定默认开启**，所以 `{Binding}` 就是编译绑定，必须配 `x:DataType`（本项目每个视图根节点 + DataTemplate 都有）。
- DataContext 三条传递链：MainWindow.DataContext=shell → ContentControl.Content(DataTemplate 把 DataContext 设为该 page VM) → ItemsControl.ItemsSource(每项 item 成为模板 DataContext)。
- 模板内访问外层 VM：`{Binding $parent[ItemsControl].((vm:SettingsViewModel)DataContext).CopyIpnsCommand}`；item 自身：`CommandParameter="{Binding}"`。
- 语法糖：`{Binding !IsHomePage}` 布尔取反（替代 converter）；派生属性走计算属性 + `[NotifyPropertyChangedFor]`（HasCover/ViewModeText/FileCountText/IsEmpty），不用 StringFormat/Converter。
- DetailView 用 DataContextChanged 事件补挂 VideoSurface.MediaPlayer（DataContext 晚于视图构造到达）。
